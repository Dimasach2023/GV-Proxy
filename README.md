# GV proxy

Локальный прокси для Windows, который заменяет «мёртвые» узлы `googlevideo.com`
(`rrN---sn-pivhx-*.googlevideo.com`) на рабочий узел, взятый из параметра `mn=` самой ссылки на видео.
Если YouTube зависает на загрузке потока, потому что браузеру достался недоступный узел, прокси
незаметно подставляет другой.

- Только Windows.
- Не требует ничего, кроме Python 3: если его нет, установочный `.bat` поставит его сам.
- Всё, что скрипт меняет в системе, он умеет откатить одной командой.

## Как это работает

1. В файл `hosts` добавляются записи, которые направляют адреса «мёртвых» узлов из `blocked.txt` на `127.0.0.1` / `::1`.
2. Браузер подключается к прокси на `127.0.0.1:443`.
3. Прокси завершает TLS своим сертификатом для `*.googlevideo.com`.
4. Из параметра `mn=` в запросе он выбирает рабочий узел, подключается к нему (с его SNI и `Host`)
   и подменяет заголовок `Host`.
5. Дальше байты просто пересылаются в обе стороны.

Если узел отвечает ошибкой (`400`, `403` или `5xx`) или не отвечает, прокси пробует следующий.
Для надёжности подключения к одному узлу запускаются с небольшой задержкой друг за другом,
а результаты DNS кэшируются.

## Установка

1. Распакуйте архив в постоянную папку, например `C:\Tools\GV-proxy`.
   **Не перемещайте её после установки**: автозапуск ссылается на путь к `gv_proxy.py`.
2. Запустите `gv_proxy_setup.bat`. Он сам запросит права администратора.
3. Если Python 3 не найден, скрипт установит его автоматически (через `winget`, а если не получится,
   скачает установщик с python.org). Библиотека `cryptography` ставится через pip.
4. В меню выберите **1 - Install**.
5. **Полностью перезапустите Chrome или Edge.**

Firefox не использует системные сертификаты, поэтому с ним прокси работать не будет.

### Меню `gv_proxy_setup.bat`

| Пункт | Что делает |
|-------|------------|
| 1 | Установка: сертификат + `hosts` + фоновый запуск без окна + автозапуск при входе в Windows |
| 2 | Остановить прокси и убрать автозапуск (`hosts` и сертификат остаются) |
| 3 | Сертификат и `hosts` + запуск прокси в окне (тестовый режим) |
| 4 | Только запустить прокси в окне |
| 5 | Удалить всё: автозапуск, записи в `hosts`, сертификат, сгенерированные файлы |
| 6 | Выход |

Пункт 3 удобен для первой проверки: в окне видно лог в реальном времени.

## Настройка: `blocked.txt`

Список узлов, которые нужно перенаправлять. Один адрес на строку, `#` начинает комментарий.
Принимаются три формы:

```
rr3---sn-pivhx-n8vs.googlevideo.com    # один конкретный адрес
rr*---sn-pivhx-n8vs.googlevideo.com    # этот узел на всех rr1..rr30
sn-pivhx-n8vs                          # короткая запись предыдущего варианта
```

Куда перенаправлять, прокси решает сам по `mn=` в ссылке. После изменения файла запустите пункт **1**
ещё раз: он обновит записи в `hosts`.

Если файла нет, при установке он создаётся со списком по умолчанию (узлы `sn-pivhx-n8vs`, `n8vz`, `n8v6`, `n8vd`).

## Безопасность

Скрипту нужно доверенное расширение системы, поэтому стоит понимать, что именно он делает:

- **Сертификат.** Создаётся собственный корневой сертификат `GV Local CA (googlevideo.com only)` и
  добавляется в доверенные корневые через `certutil`. У него ограничение по именам (name constraints):
  он может подписывать только `googlevideo.com` и поддомены, для остальных сайтов он недействителен.
  Закрытый ключ этого корневого сертификата сразу после генерации выбрасывается; остаётся только
  ключ листового сертификата `*.googlevideo.com`.
- **`hosts`.** Скрипт добавляет и удаляет только свои строки (между маркерами `GV-PROXY-BEGIN` / `GV-PROXY-END`).
  Всё остальное в файле остаётся нетронутым.
- **Сеть.** Прокси слушает только локальные адреса `127.0.0.1` и `::1`, порт 443.
- **Автозапуск.** Задача в Планировщике заданий `GV Proxy`, запускается при входе пользователя,
  с ограниченными правами (не от администратора).

Файлы `gv_ca.cer`, `gv_leaf.crt` и `gv_leaf.key` лежат рядом со скриптом. Не публикуйте их и не коммитьте в репозиторий.

Срок действия сертификатов около года. Когда он истечёт, выполните пункт **5**, затем пункт **1**.

## Удаление

Запустите `gv_proxy_setup.bat` и выберите **5 - Remove everything**. Будут удалены автозапуск,
свои строки в `hosts`, сертификат из доверенных корневых и сгенерированные файлы.
Саму папку проекта после этого можно удалить.

## Командная строка

Все действия, которые меняют систему, требуют прав администратора.

```
python gv_proxy.py <команда> [параметры]
```

| Команда | Описание |
|---------|----------|
| `gen` | Создать сертификаты |
| `run` | Запустить прокси в этом окне |
| `setup` | Сертификаты + доверенный корневой + записи в `hosts` |
| `install` | `setup` + фоновый запуск без окна + автозапуск |
| `uninstall-autostart` | Остановить прокси и убрать автозапуск |
| `uninstall` | Удалить всё, что установил скрипт |
| `stop` | Остановить запущенный прокси |

Параметры `run`:

| Параметр | Значение |
|----------|----------|
| `--listen ADDR` | Адрес для прослушивания, можно указать несколько раз (по умолчанию `127.0.0.1` и `::1`) |
| `--port N` | Порт (по умолчанию 443) |
| `--fallback-host HOST` | Запасной узел, если `mn=` не дал рабочего |
| `--fallback-video` | Отправлять `/videoplayback` на запасной узел, если `mn=` не помог (обычно он отвечает 400) |
| `--upstream-ip`, `--upstream-port` | Принудительный адрес узла (для отладки) |
| `--insecure-upstream` | Не проверять сертификат узла (только для тестов) |
| `--log` | Писать лог в `gv_proxy.log` (без консоли включается автоматически) |

## Если что-то не работает

- **Видео по-прежнему зависает.** Убедитесь, что браузер был полностью закрыт и открыт заново, и что это Chrome или Edge.
  Откройте `gv_proxy.log` или запустите пункт **3** и посмотрите, приходят ли запросы.
- **Прокси не отвечает на `127.0.0.1:443`.** Порт, скорее всего, занят другой программой (веб-сервер, другой прокси, VPN-клиент).
- **Нужный узел не перенаправляется.** Добавьте его в `blocked.txt` и снова выполните пункт **1**.
- **Не установился Python.** Установщик пишет лог в `%TEMP%\gv-python-install.log`. Python можно поставить вручную
  с <https://www.python.org/downloads/> (отметьте *Add python.exe to PATH*) и запустить `.bat` заново.

## Структура

```
gv_proxy_setup.bat   установщик и меню (сам просит права администратора, при необходимости ставит Python)
gv_proxy.py          прокси, управление сертификатом, hosts и автозапуском
blocked.txt          список перенаправляемых узлов
```

Во время работы рядом появляются `gv_ca.cer`, `gv_leaf.crt`, `gv_leaf.key` и `gv_proxy.log`.
