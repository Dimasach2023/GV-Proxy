# GV_Proxy

Windows-утилита для YouTube, когда видео не грузится или постоянно буферизуется из-за **мёртвых нод googlevideo** (кеш-серверы провайдера вида `rrN---sn-xxxxx-xxxx.googlevideo.com`, которые не отвечают).

Утилита перехватывает соединения к таким нодам через [WinDivert](https://github.com/basil00/WinDivert) и прозрачно подменяет их на рабочую ноду. Рабочая нода берётся из параметра `mn=` в самой ссылке на видео. Файл `hosts` не трогается.

> Статус: экспериментальный. Логика перехвата пакетов и прокси покрыта тестами, но на реальных Windows-машинах проверена мало. Если что-то не работает, откройте issue и приложите вывод пункта «Диагностика».

## Как это работает

1. Из имён в `blocked.txt` утилита узнаёт IP-адреса мёртвых нод (обычным DNS) и раз в 5 минут обновляет их.
2. WinDivert перенаправляет TCP-соединения на эти адреса (порт 443) на локальный прокси (порт `18443`). QUIC (UDP/443) к ним отбрасывается, чтобы браузер перешёл на TCP.
3. Прокси расшифровывает TLS собственным сертификатом `*.googlevideo.com`, читает `mn=` из ссылки, соединяется с рабочей нодой и пересылает данные.

Сертификат нужен потому, что `mn=` передаётся внутри TLS, и без расшифровки его не прочитать.

## Требования

- Windows 10 / 11, x64
- Права администратора
- Python 3 (установщик поставит сам через winget или с python.org, если его нет)
- Chrome, Edge или другой браузер на Chromium. Firefox не использует системные сертификаты, поэтому в нём не заработает.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте в постоянную папку, например `C:\gv_proxy`. Не переносите её после установки: автозапуск ссылается на этот путь.
2. **Впишите свои ноды в `blocked.txt`** (см. ниже). Это обязательный шаг: у каждого провайдера свои ноды.
3. Запустите `gv_proxy_setup.bat` (запросит права администратора) и выберите **1 — Install service**.
4. Полностью закройте и заново откройте браузер.

Установка добавляет корневой сертификат, правило брандмауэра для порта `18443` и задачу автозапуска `GV Proxy` в Планировщике. Прокси работает в фоне без окна.

## Что вписать в blocked.txt

У разных провайдеров разные кеш-ноды, поэтому список в репозитории — только пример. Узнать свои:

1. Откройте любое видео на YouTube, которое грузится плохо.
2. Нажмите `F12` → вкладка **Network** → в фильтре введите `videoplayback`.
3. Найдите запросы, которые висят (Pending), красные или с ошибкой (`ERR_CONNECTION_...`, `ERR_TIMED_OUT`). Откройте любой такой запрос → **Headers** → **Request URL**:

   ```
   https://rr1---sn-pivhx-n8vs.googlevideo.com/videoplayback?...&mn=sn-pivhx-n8vs,sn-n8v7kne6&...
   ```

4. В хосте (`rr1---sn-pivhx-n8vs.googlevideo.com`) вам нужна часть **`sn-pivhx-n8vs`**. Обычно в `mn=` первым стоит нода провайдера (мёртвая), вторым — обычная нода Google (рабочая). Если один запрос завис, а повторный с другим хостом прошёл, мёртвый тот, что завис.
5. Откройте `blocked.txt` и добавьте строку на каждую мёртвую ноду:

   ```
   sn-pivhx-n8vs
   sn-pivhx-n8vz
   ```

   Допустимые формы записи (одна запись на строку, `#` начинает комментарий):

   | Запись | Что означает |
   |---|---|
   | `sn-pivhx-n8vs` | эта нода на всех `rr1`…`rr30` (рекомендуется) |
   | `rr*---sn-pivhx-n8vs.googlevideo.com` | то же самое, полная форма |
   | `rr3---sn-pivhx-n8vs.googlevideo.com` | только один конкретный адрес |

6. Соберите несколько видео и перезагрузите страницу: у одного провайдера обычно 2–4 ноды с общим префиксом. Впишите все, которые видели.

Чтобы изменения применились: список перечитывается сам раз в 5 минут, либо запустите `gv_proxy_setup.bat` → **1** ещё раз.

Прокси также не выбирает запасную ноду из того же семейства: если вы вписали `sn-pivhx-n8vs`, все ноды `sn-pivhx-*` считаются непригодными для подмены.

## Меню gv_proxy_setup.bat

| Пункт | Действие |
|---|---|
| 1 — Install service | установка: сертификат, правило брандмауэра, автозапуск, запуск |
| 2 — Remove service | полное удаление: автозапуск, сертификат, правило брандмауэра, папка `data` |
| 3 — Diagnostics | проверка: права, WinDivert, найденные адреса мёртвых нод, фильтр |
| 4 — Exit | выход |

## Если не работает

1. Выберите **3 — Diagnostics**. В выводе должны быть найденные адреса («dead addresses» больше 0) и строка `WinDivert driver: loads and opens OK`.
2. Посмотрите лог `data\gv_proxy.log`. Строки `[divert] ... -> local proxy` значат, что соединения перехватываются, а строки `rrN---... -> rrN---... => 200` — что подмена прошла.
3. Нет адресов: проверьте написание нод в `blocked.txt` и что имена вообще резолвятся (`nslookup rr1---sn-xxxx-xxxx.googlevideo.com`).
4. Ошибка драйвера (`577`, `1275`): Windows блокирует драйвер (Secure Boot, «Целостность памяти», антивирус). Эта же проблема бывает у zapret и других программ на WinDivert.
5. После установки видео всё равно висит: полностью закройте браузер (в том числе в трее) и откройте заново. В Chrome отключите «Безопасный DNS» (DoH), если IP нод в нём отличаются от системных.

## Ограничения

- Адреса нод определяются через системный DNS. Если браузер использует DoH и получает другие IP для тех же имён, перехват не сработает.
- Перенаправляются все соединения на IP мёртвых нод, а не только запросы к `googlevideo.com`. Для обычных кеш-нод провайдера это нормально, но другие сайты на тех же IP (если они есть) работать не будут.
- Прокси слушает порт `18443` на всех интерфейсах, но принимает только соединения, пришедшие через перенаправление с адресов мёртвых нод; остальные закрывает сразу.
- Сертификат действует около года. Когда истечёт, выполните **2 — Remove**, затем **1 — Install**.
- Только Windows x64.

## Совместимость с zapret

Работает рядом с zapret / winws: у утилиты приоритет WinDivert выше (1000), поэтому подмена происходит раньше, а исходящие соединения прокси к рабочим нодам проходят через zapret как обычно. Используется та же версия WinDivert 2.2.2, что и в zapret.

## Безопасность

- Корневой сертификат создаётся локально и **ограничен доменом `googlevideo.com`** (Name Constraints): он не может подписать сертификат для других сайтов.
- Закрытый ключ корневого центра не сохраняется: после создания листового сертификата он удаляется. Листовой ключ лежит в `data\gv_leaf.key`: не публикуйте его.
- Всё сделанное при установке откатывается пунктом **2 — Remove service**.
- Бинарные файлы WinDivert в `bin\` взяты из официального релиза [v2.2.2](https://github.com/basil00/WinDivert/releases/tag/v2.2.2) (SHA-256 архива `63cb41763bb4b20f600b6de04e991a9c2be73279e317d4d82f237b150c5f3f15`). Вы можете заменить их своими.

## Структура

```
gv_proxy_setup.bat   установщик / меню
blocked.txt          список мёртвых нод
src/gv_proxy.py      сам прокси и перехват пакетов
bin/                 WinDivert 2.2.2 x64 (DLL, драйвер, лицензия)
data/                создаётся при установке: сертификат, ключи, лог
```
